# AlphaPi One S 双固件 · 六段式刷机包（v16 · 小智 + M2b 日期色收音机）

一次写入 6 个镜像：`ota_0` = 小智 + **自定义深色时钟页/中文天气**，`ota_1` = **M2b 日期色网络收音机**。
两块固件靠 `otadata` 切换，D 长按互切。打包日期 2026-11-12。

> **从 v15 升级只需写一段（收音机）**，小智、otadata、nvs、assets 全不动，Wi-Fi 与天气设置不丢：
> `python -m esptool --chip esp32s2 -p COMx -b 115200 --before no_reset --after no_reset write_flash 0x310000 radio.bin`
> 回滚：把文件名换成 `extras/radio-v15-原版回滚.bin` 重刷同一地址即可，逐字节还原。
> **参数必须用下划线** `no_reset` / `default_reset`：本机 esptool 4.8.1 不认连字符写法
> `no-reset`（会报 `invalid choice`），旧版 README 里的连字符命令已在本包统一修正。
>
> **从 v14 及更早升级**，除上述收音机段外还要多写两段（v15 换了完整资源包）：
> `python -m esptool --chip esp32s2 -p COMx -b 115200 --before no_reset --after no_reset write_flash 0x20000 xiaozhi.bin 0x600000 generated_assets.bin`
> 只写 0x20000 也能用（v14 固件已把深色底色锁在 `#0E1420`），但资源包里的色值不会跟着变。

**v14 修正（2026-11-12）：状态栏那 22px 的色差 —— 真因是资源包改了主题底色**

1. **真因**：`assets.bin` 里的 `index.json` 写着
   `"skin": { "dark": { "background_color": "#1f2937" } }`。
   启动时 `Assets::LvglStrategy::Apply()` 会把它覆盖到深色主题上，
   于是状态栏、聊天页底色变成 `#1F2937`（比首页亮一档），而自定义首页写死 `#0E1420`
   —— 顶部整条 22px 就成了一条更亮的色带。上一版判断成"脏区没重绘"是错的。
2. **另一个连带 bug**：`CONFIG_USE_WECHAT_MESSAGE_STYLE` 没开，真正编译的是
   `lcd_display.cc` 第 857 行那份 `SetupUI()`；v10 改的是第 387 行那份（死代码），
   而且 `SetTheme()` 每次都把 `top_bar_` 重新设成 `LV_OPA_50`。所以之前几版都没生效。
3. **修法**（`display/lcd_display.cc`）：
   - 活跃的 `SetupUI()` 与 `SetTheme()` 里，顶部条一律 `LV_OPA_COVER`（不透明）。
   - `SetTheme()` 开头把**深色主题**的 `background_color` / `chat_background_color`
     锁回 `#0E1420`（浅色主题不动），状态栏、聊天页、首页从此共用一个色值。
     `assets.Apply()` 先覆盖、后调 `SetTheme()`，所以锁色一定在皮肤之后生效。
4. 仅 `xiaozhi.bin` 变化（2,220,320 → 2,220,464 B，md5 `f9415214…`）；其余五段与 v13 逐字节一致。

**v5 修复两处（2026-11-11 实测反馈）**

1. **收音机长按 D 切回小智会卡死**：本工程 `main.cc` 里有两个"开发便利"开关，
   其中一个在 `app_main` 最开头读 D 键，只要开机瞬间 D 还按着（收音机切回正是长按 D 触发，
   `esp_restart()` 后手指常常还没松），就调用 `ForceDownloadMode()` 把芯片强制拖进
   **ROM 下载模式** —— 黑屏、无响应、只能断电，看起来就是"死机"。
   另一个四键 helper 也可能被余电平误触发。v5 把两个开关都关掉，字符串已从固件里彻底消失；
   刷机改由脚本 `--before default-reset` 自动进下载模式。
   另外补了两道保险：开机 5 秒内忽略 D 长按切槽（防止残留按键把系统又弹回收音机）；
   `app_main` 立刻 `esp_ota_mark_app_valid_cancel_rollback()` 确认镜像，
   切槽后也把新槽标成 `VALID`，避免 PENDING_VERIFY / rollback 干扰互切。
2. **天气设置好以后 IP 自动消失**：`IP x.x.x.x` 只在"还没保存过天气位置"时显示，
   保存成功后 1 秒内从表盘移除；已配置的设备开机也不再显示。
   以后忘了解设备 IP，可访问配置页点「**在屏幕上重新显示 IP**」临时显示 60 秒。

> 与别人给的「移植版-双固件-20261111」相比，**只替换了 `xiaozhi.bin`**。
> 其余五段（bootloader / 分区表 / otadata / radio / assets）逐字节沿用原包，均已验证可用。
> `xiaozhi.bin` 是自行重编的 v14：深色 `#0E1420` + 青 `#8FE3F0` / 暖黄 `#FFD27A` 时钟页、
> `alphapi_cn_16` 中文字库、中文天气与温度、矢量天气图标、三天预报；不含收音机代码（收音机在另一个槽）。

## 二、刷机前必做

1. 让板子进入 **ROM 下载模式**：电源开关拨 **OFF → 等 2 秒 → ON**，并保持你平时进下载模式的那个动作。
   这块板靠拨动瞬间 GPIO0 采到低电平，是概率事件，没进去就多拨一两次；
   一键脚本用 `--before default-reset` 也能自动触发，不需要靠按键（v5 固件已去掉按键辅助开关）。
2. 关掉**浏览器网页刷机页**和任何串口监视器，它们会独占 COM 口。
3. 设备跑应用时 COM 口是 TinyUSB CDC，esptool 打不开；必须停在 ROM 下载器里。
   反之，如果 esptool 报 `PermissionError(13) 拒绝访问` 且设备管理器里该 COM 口显示
   `CM_PROB_PHANTOM`，那是**板子断电后留下的幽灵节点**，重新上电即可，查进程占用没用。

## 三、三种刷法

### 方法 1：一键脚本（推荐）

双击 **`flash_all.bat`**，或命令行：

```
python flash_all.py              # 自动找串口，等板子进下载模式
python flash_all.py COM20        # 指定串口
python flash_all.py --check-only # 只校验六段文件，不烧录
```

脚本会：校验六段 md5 → 自动发现端口（认 USB VID `2F4E`/`303A`，排除 COM1 和 18 个
SPRD 手机调试口）→ 探测到 ROM 下载器后**一次写六段** → 统计 `Hash of data verified`，
应为 **6/6**；若中途失败会自动回退成逐段重试。
优先用本机 ESP-IDF 的 esptool 4.8.1，找不到就用系统 Python 的 esptool
（新电脑先 `pip install esptool pyserial`）。

### 方法 2：网页刷机页（不想敲命令）

双击 **`start-web-flasher.cmd`** → 浏览器打开 `http://localhost:8123/...`。
点「**AlphaPi One S 六段布局（小智+收音机）**」按钮，页面会自动读取本目录同名的 6 个 `.bin`
并填好地址；然后「连接 → 烧录」（建议勾校验）。
必须走 `http://`，直接双击 html 用 `file://` 打开会拿不到 Web Serial 权限。

### 方法 3：esptool 手打

先进 ROM 下载模式，然后（端口按实际改）：

```
python -m esptool --chip esp32s2 -p COM20 -b 115200 ^
  --before no_reset --after no_reset ^
  write_flash -fm dio -fs 8MB -ff 80m ^
  0x001000 bootloader.bin ^
  0x008000 partition-table.bin ^
  0x00D000 ota_data_initial.bin ^
  0x020000 xiaozhi.bin ^
  0x310000 radio.bin ^
  0x600000 generated_assets.bin
```

**烧完请手动拨一次 OFF → ON 正常开机**（不进下载模式）。本板 RTS 接不到 EN，
软件 `hard-reset` 通常无效，别以为刷完没反应就是失败。

## 四、天气位置设置（v4 新增，v5/v6 调整 IP 显示）

1. **首次开机（还没设过位置）**：联网后时钟页**右上角**显示 `IP 192.168.x.x`
   （还没联网时是 `IP --`）。手机 / 电脑连到**同一个 Wi-Fi**，浏览器打开
   `http://<屏幕上的那串 IP>/`。
2. **保存成功后 IP 自动从屏幕上消失**（约 1 秒内），以后开机也不再显示，表盘保持干净。
   配置页仍在 80 端口常驻；忘了解 IP 时可从路由器客户端列表、浏览器历史记录找回，
   或进配置页点「**在屏幕上重新显示 IP**」临时显示 60 秒。
3. 页面里可以：
   - 从「选择城市」下拉挑 47 个国内主要城市，选中会自动填好经纬度；
   - 或选「自定义」，直接填纬度 / 经度，并填写屏幕显示名称；
   - 点「**保存并立即刷新天气**」→ 写入 NVS，设备立刻重新拉取天气，屏幕右下角城市名同步变化；
   - 「**按公网 IP 自动定位**」会调用 `ip-api.com` 尝试识别出口城市。国内网络可能访问不了，
     失败会回到页面并提示，手动选城市即可。
4. 设置存在 `nvs` 的 `weather` 命名空间，**重启不丢**；本包六段不含 `nvs` 分区，
   所以全量重刷也不会清掉已设置的城市和 Wi-Fi。
5. 屏幕字库 `alphapi_cn_16` 只收录了列表内城市用到的汉字和常用字。自定义中文名若含
   字库外的字会显示方框 —— 自定义时建议用英文 / 拼音，或直接选列表内城市；
   网页里的中文不受影响。

> 配置页只在**联网后**启动（80 端口），不联网访问不到；它跟小智对话、配网 AP 互不干扰。

## 五、按键（v5/v6 实际行为）

**小智侧（ota_0）**

| 按键 | 动作 |
|---|---|
| A 短按 | 开始 / 结束对话（开机启动阶段 = 进配网） |
| **A 长按 3 秒** | **进配网 / 再长按退出配网回时钟页**（toggle） |
| B 短按 | 音量 −10 |
| C 短按 | 音量 +10 |
| D 短按 | 静音 / 恢复 |
| **D 长按** | **切到 ota_1 网络收音机并重启**（开机 5 秒内忽略，避免切回时的残留按键误触发） |

> v5 起**固件内不再有「开机按 D / 四键组合进 ROM 下载模式」的辅助开关**（会误触发，
> 见开头）。要刷机请用脚本 `--before default-reset`，或拨电源开关 OFF → ON 进下载模式。

> 注意：别人那份 README 写的是「B 加 / C 减」，本工程实测 B 在左、C 在右，
> 所以这里是 **B 减 / C 加**，以本包为准。

**收音机侧（ota_1，原版行为）**

- A 短按：播放 / 暂停；A 长按：电台列表
- B / C 短按：上一台 / 下一台；长按：音量
- D 短按：静音；**D 长按并继续按住约 3 秒：切回小智**

## 七、注意事项

- **小智的自动 OTA 已在本固件里停用**。原版「检查新版本」会把新固件写进 ota_1，
  覆盖收音机；停用后就不会。以后升级小智需手动重刷 `0x020000`。
- 万一收音机起不来，或只想换收音机颜色，**单独重刷一段即可**（不用全量），
  小智 / nvs / otadata / assets 全部不受影响：
  ```
  python -m esptool --chip esp32s2 -p COM20 -b 115200 --before no_reset --after no_reset write_flash 0x310000 radio.bin
  ```
  回滚把 `radio.bin` 换成 `extras/radio-v15-原版回滚.bin`。
  刷完**手动拨一次 OFF → ON** 正常开机。注意 esptool 4.8.1 用 `no_reset`（下划线），
  不认 `no-reset`；波特率保持 115200，实测本机 USB 串口切到 460800 / 921600 会失去响应。
- `extras/` 目录（可选资料，刷机用不到）：`radio-v15-原版回滚.bin` 回滚镜像、
  `patch_radio_m2b.py` 本包所用补丁脚本、`patch_radio_m2.py` 上一版 M2 脚本、
