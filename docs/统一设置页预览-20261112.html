改动说明（本次固件）

① 卡死：查到 4 个确定性隐患，全部修掉

1 · LVGL 刷新重入（最可能的真凶）：v13 排查状态栏色差时，在 LVGL timer 回调里加了 lv_refr_now(nullptr)；真因 v14 已经查明是 assets 里 skin.dark 的 #1f2937 覆盖主题色，这行早就没有作用。它会在 timer handler 内重入显示刷新，与 esp_lvgl_port 的 flush / mutex 撞车时死锁；LVGL 锁一旦不释放，Application 主循环每秒的 UpdateStatusBar() 就一直等锁（DisplayLockGuard 最长 30 s），整机表现为「用一段时间有概率卡死」。已删除，只保留 invalidate。

2 · 每秒无谓重写：UpdateText() 原来无条件重设 12 个 label 文本、11 个对象显隐 flag，还做 3 次 lv_obj_update_layout()。lv_label_set_text 即使文本相同也会重新分配并复制字符串、把对象标脏；ESP32-S2 没有 PSRAM，长期运行后 LVGL 堆碎片化，最终分配失败 / 刷新卡住。已加文本缓存，只在内容真的变化时写 LVGL。

3 · esp_timer 任务栈只有 3584 B：SNTP 初始化和建 UI（40+ LVGL 对象 + 4 组矢量图标）原来都跑在 ESP_TIMER_TASK 回调里，还要等 LVGL 锁。栈溢出会静默踩坏内存、之后随机发作；一旦阻塞则所有软件定时器停摆。已改成独立 4096 B FreeRTOS 任务。

4 · 两个 httpd 抢 80 端口：天气设置页和配网 AP 页各起一个 80 端口 server，进 / 出配网时抢占结果不确定，ESP_ERROR_CHECK(httpd_start) 失败还会直接 abort。已合并为唯一 server（见下）。

② 统一设置页：一个页面、一个 httpd

天气 httpd 改为开机 3 秒起、绑 0.0.0.0:80，不再等 STA 拿到 IP，因此 STA 与 AP 两种模式都能访问；配网 AP 只保留热点 / DNS / 周期扫描，不再启动第二套 web server（组件里 StartWebServer() 一处注释）。页面最上面是 Wi-Fi 配网，下面才是天气位置设置。

新增路由：GET /wifi/scan（扫描结果 JSON）、POST /wifi/save（存凭据并重连）、GET /wifi/mode?enter=0|1（进 / 出配网模式）、GET /*（captive portal 兜底跳回本页）。原有 /save、/geo、/showip 全部保留。

行为变化，请留意：官方配网 SPA 的「多 SSID 管理 / 高级设置」不再通过网页提供，换成本页的「扫描列表 + 填 SSID / 密码」。首次配网仍可用：进入配网模式后连设备热点，浏览器打开 http://192.168.4.1/ 看到的就是本页；也可以长按 A 键 3 秒进 / 出配网模式。

链接器顺带回收了那 78 KB 的配网页 HTML 与相关 handler：新固件 2,135,424 B，比 v15 的 2,220,464 B 小 85 KB。
